Professional Self-Assessment

Throughout my Bachelor of Science in Computer Science program at Southern New Hampshire University, I have developed a better understanding of how different areas of computer science connect. My education has involved more than learning programming languages or completing individual assignments. I have learned how to analyze problems, evaluate solutions, design applications, work with data, and consider security and reliability throughout development. My Mathematics minor has also strengthened my analytical thinking and approach to problem-solving.

My coursework has covered programming, data structures and algorithms, software engineering, operating platforms, systems analysis and design, databases, software security, and testing. These subjects have helped me understand the importance of planning, selecting appropriate solutions, and evaluating how different components work together. I have learned that getting a program to run is only part of developing a reliable application.

Through projects such as my course-planning application and client/server database application, I gained experience organizing information, implementing program logic, and working with stored data. These projects helped me apply concepts from my coursework and improve how I approach technical problems.

Communication has also been an important part of my education. Since my coursework was completed online, much of my interaction with classmates involved discussion posts, peer responses, and exchanging different perspectives. These activities helped me practice explaining my ideas, considering other viewpoints, and supporting decisions with evidence. Written assignments, project documentation, and presentations also helped me communicate technical information more clearly.

My software security and testing coursework taught me to consider vulnerabilities, validation, and reliability during development. I applied these concepts in my capstone by improving authentication handling, input validation, and API error responses. These improvements reinforced the importance of protecting information and testing how an application behaves when something goes wrong.

For my CS 499 capstone, I selected Travlr Getaways, a full-stack travel application originally developed in CS 465. My software engineering enhancement improved application structure, configuration, validation, error handling, and maintainability. My algorithms and data structures enhancement improved how trip information is processed and organized repeated logic into reusable functions. My database enhancement strengthened MongoDB validation, improved connection handling, introduced aggregation functionality, and made database seeding safer.

Together, these enhancements demonstrate how software design, algorithms, databases, and security contribute to a complete application. Reviewing my original work, identifying weaknesses, implementing changes, and testing the results helped me apply knowledge from several courses to one project.

As I continue my education and work toward a career in computer science, I want to build on the foundation I developed at SNHU. My interests include programming, data analysis, databases, and other technical areas involving analytical thinking and problem-solving. I value having experience across different areas of computer science rather than limiting myself to one specialization.

This ePortfolio presents my code review, original and enhanced artifacts, and technical narratives. Together, they demonstrate my academic development, technical abilities, and the progress I have made throughout the Computer Science program.

Software Engineering and Design

Travlr Getaways Enhancement

For my software engineering and design enhancement, I used the Travlr Getaways full-stack web application originally developed in CS 465. The application uses the MEAN stack, including MongoDB, Express, Angular, and Node.js.

I improved the project by refactoring API configuration, improving asynchronous code, correcting single-trip API handling, centralizing Angular service configuration, and improving error handling throughout the application.

I also added stronger client-side and server-side validation, improved JWT authentication error handling, removed unnecessary authentication debugging output, and prevented internal application details from being exposed in API error responses.

These changes improved the maintainability, reliability, usability, and security of the application while preserving the original functionality.

Databases

Travlr Getaways MongoDB Enhancement

For my database enhancement, I improved the MongoDB implementation used by the Travlr Getaways application. I strengthened schema validation, improved database error handling, and added aggregation functionality to calculate statistics from stored trip information.

I also verified the use of a unique index for trip codes and improved the database seeding process so existing records would not be unnecessarily overwritten.

These improvements demonstrate my understanding of database design, data integrity, query operations, and reliable application development.
